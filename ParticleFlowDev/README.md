# Particle Flow development files

Here you will find a new version of the Particle Flow reconstruction and evaluator code. The particle flow reconstruction includes some modifications in the particle flow element code too. As for the evaluator, it contains also Topo Cluster evaluators.

All code here is tested, but maybe it's not straightforward to make it work. In specific, having the right objects such as RawTower vs TowerInfo, or the right EMCal geometry available will make a big difference.
